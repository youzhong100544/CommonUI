基础知识


正则表达式（Regular Expression，简称 Regex 或 RegExp）是一种用来匹配字符串中字符组合的模式。
正则表达式是一种用于模式匹配和搜索文本的工具。
正则表达式提供了一种灵活且强大的方式来查找、替换、验证和提取文本数据。

正则表达式（英语：Regular Expression，在代码中常简写为regex、regexp或RE）使用单个字符串来描述、匹配一系列符合某个句法规则的字符串搜索模式。
搜索模式可用于文本搜索和文本替换。





入门案例

需求1：判断一个字符串是否包含特定字符串 


			// 判断字符串中是否包含 'o' 这个字符
			var str = "hello world";
			var re = /o/;
			
			console.log(re.test(str)); // true
			
			console.log(re.exec(str)); // ['o', index: 4, input: 'hello world', groups: undefined]

			console.log(str.match(re)); // ['o', index: 4, input: 'hello world', groups: undefined]


需求2：判断一个字符串是否包含特定字符串 


			// 判断字符串中是否包含 'o' 这个字符
			var str = "hello world";
			var re = /o/g;
			
			console.log(re.test(str)); // true
			
			console.log(re.exec(str)); // ['o', index: 7, input: 'hello world', groups: undefined]

			console.log(str.match(re)); // ['o', 'o']




创建正则表达式

你可以使用以下两种方法构建一个正则表达式：

1、使用一个正则表达式字面量，其由包含在斜杠之间的模式组成 

			var re = /pattern/modifiers;
2、调用RegExp对象的构造函数 

			var re = new RegExp(pattern, modifiers);
		
● pattern（模式） 描述了表达式的模式
● modifiers(修饰符) 用于指定全局匹配、区分大小写的匹配和多行匹配
注意：当使用构造函数创造正则对象时，需要常规的字符转义规则（在前面加反斜杠 \）。
比如，以下是等价的： 

			var re = /\w+/;
			var re = new RegExp("\\w+");
		

			var re = /^\d+$/;
			var re = new RegExp("^\\d+$");

常用方法

  • match()
  • replace()
  • search()
  • exec()
  • test()
test()
	- 功能：检测字符串是否包含正则表达式匹配的模式，返回布尔值（true或false）。
	- 返回值：仅判断是否存在匹配，不返回具体匹配内容。

exec()
	- 功能：返回第一个匹配项的详细信息（包括分组、位置等），若未匹配则返回null。
	- 返回值：数组形式，包含匹配内容、分组结果、index（匹配起始位置）和input（原始字符串）。

match()
	- 功能：从字符串中提取所有匹配项（全局匹配时）或第一个匹配项（非全局匹配时）。
	- 返回值：
		- 非全局：返回包含第一个匹配项及其分组的数组。
		- 全局：返回所有匹配项的数组（忽略分组信息）。
