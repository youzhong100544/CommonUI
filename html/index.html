<!DOCTYPE html> 作用

<!DOCTYPE html> 是 HTML 文档类型声明，必须写在 HTML 文件的第一行，放在 <html> 标签之前。
它不是 HTML 标签，没有结束标签，也不区分大小写。


主要作用

作用 说明
触发标准模式 告诉浏览器按 W3C 标准渲染页面，避免进入怪异模式
声明文档类型 告诉浏览器这是 HTML5 文档
保证兼容性 让页面在不同浏览器中表现更一致

为什么它很重要？

如果缺少 <!DOCTYPE html>，浏览器可能会进入 怪异模式（Quirks Mode），模拟旧版浏览器的非标准渲染方式，可能导致：

  • CSS 盒模型计算异常（比如 width 包含 padding 和 border）
  • 页面布局错乱
  • 不同浏览器显示不一致

HTML5 写法 

<!DOCTYPE html>
<html>
	<head>
		<meta charset="UTF-8">
		<meta name="viewport" content="width=device-width, initial-scale=1.0">
		<title>页面标题</title>
	</head>
	<body>
		页面内容
	</body>
</html>

HTML 4.01 的 DOCTYPE

类型 写法 说明
Strict <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd"> 严格模式，不包含展示性、过时元素，不允许框架集
Transitional <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd"> 过渡模式，允许部分过时元素和属性
Frameset <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Frameset//EN" "http://www.w3.org/TR/html4/frameset.dtd"> 允许使用 <frameset> / <frame></frame>

XHTML 1.0 的 DOCTYPE

类型 写法 说明
Strict <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd"> 严格 XML 格式，不允许表现性元素
Transitional <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd"> 允许部分过时元素
Frameset <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Frameset//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-frameset.dtd"> 允许框架集

XHTML 1.1 的 DOCTYPE 

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.1//EN" "http://www.w3.org/TR/xhtml11/DTD/xhtml11.dtd">
